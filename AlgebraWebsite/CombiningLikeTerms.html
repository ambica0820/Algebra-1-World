Combining Like Terms

Combining like terms is a fundamental concept in algebra that allows us to simplify expressions by adding or subtracting terms that have the same variable raised to the same power.

What are Like Terms?

Like Terms are terms that have the same variable and variables that are raised to the same power.

Rules for Combining Like Terms:

  • Coefficients (the numbers in front of the variables) can be different.

  • Terms must have the same variable.

    • For example, 3x and 5x are like terms because they both have the variable x

  • Terms must have the same exponent (power) on that variable.

    • For example, 2y2 and 4y2 are like terms because they both have the variable y raised to the same power (2).

  • Terms with different variables or different powers cannot be combined.

    • For example, 7a and 3b are not like terms because they have different variables (a and b). Similarly, 5m3 and 2m2 are not like terms because they have the same variable (m) but different powers (3 and 2).

Like Terms (Yes or No)

Expression Like Terms? Explanation
3X + 5X Yes Both terms have the variable x raised to the same power (1).
2Y2 + 4Y2 Yes Both terms have the variable Y raised to the same power (2).
7A + 3B No The terms have different variables (A and B).
5M3 + 2M2 No The terms have the same variable (m) but different powers (3 and 2).

How to Combine Like Terms:

To combine like terms, simply add or subtract the coefficients (the numbers in front of the variables) while keeping the variable part unchanged.

For example:

  • 3X + 5X = (3 + 5)X = 8X
  • 2Y2 + 4Y2 = (2 + 4)Y2 = 6Y2
  • 7A - 3A = (7 - 3)A = 4A
