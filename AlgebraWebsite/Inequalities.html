Inequalities

What is an inequality?

An inequality is a math sentence that compares two values or expressions using an inequality symbol.

Inequality Symbols

There are 4 inequality symbols.

Symbol What it means
> Greater than
< Less than
≥ Greater than or equal to
≤ Less than or equal to

How To Solve Inequalities

The steps to solve inequalities are very similar to solving equations. The main difference is the inequality symbols.

Steps:

  1. Simplify both sides of the inequality. Combine like terms if necessary.
  2. Use addition or subtraction to move constants and isolate the variable term.
  3. Use multiplication or division to isolate the variable.
  4. Write your solution with the correct inequality symbol.
  5. Check your answer by substituting a value into the original inequality.

Examples

Example 1: 4x ≤ 3x + 2

  1. Subtract 3x on both sides of the inequality. We now get 1x ≤ 2.
  2. Our goal is to get x by itself now. We divide by 1 on both sides.
  3. 2 ÷ 1 is 2.

Final Answer: x ≤ 2

Example 2: x + 7 > 12

  1. Subtract 7 from both sides of the inequality. We now get x > 5.
  2. Our variable is already by itself.

Final Answer: x > 5

Example 3: 3x ≥ 15

  1. Our goal is to get x by itself.
  2. Divide both sides by 3. We now get x ≥ 5.
  3. 15 ÷ 3 is 5.

Final Answer: x ≥ 5

Dividing and Multiplying with Negatives

When solving an inequality, remember that if we multiply or divide both sides by a negative number, we must reverse the inequality symbol.

Example 1: -2x > 8

  1. Our goal is to get x by itself.
  2. Divide both sides by -2.
  3. Because we are dividing by a negative number, we must reverse the inequality symbol.
  4. We now get x < - 4.

Final Answer: x < - 4

Example 2: -3x ≤ 12

  1. Our goal is to get x by itself.
  2. Divide both sides by -3.
  3. Because we are dividing by a negative number, we reverse the inequality symbol.
  4. 12 ÷ -3 is - 4.
  5. We now get x ≥ - 4.

Final Answer: x ≥ - 4

Example 3: -2x + 5 > 11

  1. Subtract 5 from both sides. We now get -2x > 6.
  2. Divide both sides by - 2.
  3. Because we are dividing by a negative number, we reverse the inequality symbol.
  4. 6 ÷ - 2 is - 3.

Final Answer: x < - 3

REMEMBER:

When multiplying or dividing both sides of an inequality by a negative number, reverse the inequality symbol.

Graphing Inequalities on a Number Line

Graphing an inequality on a number line helps us visualize all the numbers that make the inequality true.

Steps for Graphing an Inequality

  1. Solve the inequality.

    Isolate the variable on one side of the inequality.

  2. Find the boundary point.

    The number that the variable is compared to is the boundary point. Place it on the number line.

  3. Choose an open or closed circle.
    • Use an open circle for < or >.
    • Use a closed circle for ≤ or ≥.
  4. Shade the correct direction.
    • Shade to the left for < or ≤.
    • Shade to the right for > or ≥.

Quick Reference

  • < → Open circle + shade left
  • > → Open circle + shade right
  • ≤ → Closed circle + shade left
  • ≥ → Closed circle + shade right

Example 1

Graph: x > 3

  1. Place 3 on the number line.
  2. Use an open circle because the inequality is >.
  3. Shade to the right because the numbers greater than 3 are to the right.

Solution: x > 3

Example 2

Graph: x ≤ -2

  1. Place -2 on the number line.
  2. Use a closed circle because the inequality is ≤.
  3. Shade to the left because the numbers less than or equal to -2 are to the left.

Solution: x ≤ -2

Remember: If you multiply or divide both sides of an inequality by a negative number, you must reverse the inequality sign.
