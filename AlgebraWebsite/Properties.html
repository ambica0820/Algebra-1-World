Properties

In this section, we are going to look at some addition and multiplication properties.

Note: These properties can NOT be used in subtraction and division.

Properties of Addition and Multiplication

Property Definition Example
Commutative Property The order of numbers can change, but the answer stays the same. 3 + 5 = 5 + 3
3 × 5 = 5 × 3
Associative Property The grouping of numbers can change, but the answer stays the same. (2 + 3) + 4 = 2 + (3 + 4)
(2 × 3) × 4 = 2 × (3 × 4)
Distributive Property Multiply the number outside the parentheses by each number inside. 3(4 + 2) = 3(4) + 3(2)
18 = 18
Identity Property Adding zero or multiplying by one keeps the number the same. 7 + 0 = 7
7 × 1 = 7
Zero Property Any number multiplied by zero equals zero. 9 × 0 = 0
