What is a Quadratic Equation?

A quadratic equation is an equation whose highest exponent of the variable is 2.

  • Coefficient: a number or constant value placed next to and multiplying a variable in a math expression
  • Constant: a fixed, unchanging value

Quadratic Equation Standard Form: ax2 + bx + c = 0

  • a is coefficient of x2
  • b is the coefficient of x
  • c is the constant

Factoring Quadratic Expressions

When factoring quadratic expressions, there are some things to keep in mind. We need to find two numbers that:

  • Multiply to the c term.
  • Add to the b term.

Example 1:

x2 + 7x + 12

In this example, our a is 1, b is 7 and c is 12.

  1. We first find two numbers that add to 7 and multiply to 12. Those two numbers are 3 and 4 because 3 + 4 = 7 and 3 × 4 = 12.
  2. Place the two numbers inside parentheses with x: (x + 3)(x + 4)
  3. Therefore, the factored form is: (x + 3)(x + 4)

We can also check our work by expanding the expression.

  1. x × x is x2
  2. x × 4 is 4x
  3. x × 3 is 3x
  4. 3 × 4 is 12
  5. We now get: x2 + 3x + 4x + 12
  6. Now we combine like terms. In this case thats 3x and 4x.
  7. 3x + 4x is 7x.

We get x2 + 7x + 12. Our work is correct!

Example 2:

x2 - 5x + 6

In this example, a = 1, b = -5, and c = 6.

  1. First, find two numbers that add to -5 and multiply to 6. Those two numbers are -3 and -2 because: -3 + (-2) = -5 and -3 × -2 = 6
  2. Place the two numbers inside parentheses with x: (x - 3)(x - 2)
  3. Therefore, the factored form is:(x - 3)(x - 2)

We can also check our work by expanding the expression.

  1. x × x = x2
  2. x × -2 = -2x
  3. x × -3 = -3x
  4. -3 × -2 = 6
  5. Now we have: x2 - 2x - 3x + 6
  6. Combine like terms. In this case, the like terms are -2x and -3x.
  7. -2x + (-3x) = -5x.

We get x2 - 5x + 6, which matches the original expression. Therefore, our factoring is correct!

Using the Quadratic Formula

Steps

  1. Identify a, b, and c.
  2. Write the quadratic formula.
  3. Substitute the values into the formula.
  4. Simplify inside the square root first.
  5. Simplify the numerator and denominator.
  6. Find the two values of x.

Things to Remember!

  • Always write the equation in standard form: ax2 + bx + c = 0
  • Identify a, b, and c before using the formula.
  • Remember that ± means there are two possible answers.
  • Simplify inside the square root first.
  • Check your answers by substituting them back into the original equation.

Common Mistakes

  • Forgetting to include negative signs when identifying a, b, and c.
  • Forgetting to solve both the + and − cases.
  • Using the wrong order of operations.
  • Not simplifying the square root completely.
